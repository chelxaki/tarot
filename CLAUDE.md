# Tarot Reading App

A simple three-card Tarot reading web app.

## User Flow

1. Ask one question.
2. Draw three Tarot cards.
3. Read the card meanings.
4. Save the reading.

## Stack

- Plain HTML
- Plain CSS
- Plain JavaScript
- localStorage (for saving readings)
- GitHub Pages (for hosting)

## Rules

- Keep the app simple.
- Do not use frameworks or external libraries without asking first.
- Keep the website code in `index.html`, `style.css`, and `app.js`.
- Build one feature at a time.
- Make it usable on desktop and mobile.
